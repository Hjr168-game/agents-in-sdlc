前のいくつかの演習では、ユーザーエクスペリエンスの向上と機能の追加を目的に、GitHub Copilot クラウドエージェントへ 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行された操作を調べたり、進行中のセッションに指示を追加したりすることもできます。

この演習では、次のことを行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションに指示を追加し、機能を依頼します。

## シナリオ

ハイコントラストモードの作成をエージェントに依頼した後、チームはライトモードも追加する良い機会だと気付きました。サイトのスタイルを更新し、切り替え機能を追加しているところなので、ライトモードも含めるのが自然だと考えたためです。ハイコントラストモードだけでなくライトモードも追加されるよう、エージェントの作業に指示を追加します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認しましょう。

1. [Copilot エージェントのページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスクの一覧を確認します。次のような、Copilot に割り当てたタスクが表示されます。
    - コードのドキュメントを更新する
    - ゲームを変更する API を生成する
    - Web サイトにハイコントラストモードを追加する
3. 実行中のタスクを 1 つ選択し、Copilot が実行した作業を確認します。次のような作業が表示されることがあります。
    - リポジトリをチェックアウトする
    - Copilot が作業する環境を作成する
    - MCP サーバーをセットアップする
    - 割り当てられたタスクを完了するためのさまざまな手順を実行する

> [!NOTE]
> 表示される具体的な手順は、Copilot の作業状況や選択した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは、PR と変更されたファイルを確認して、作業をさらに監視できます。

## クラウドエージェントに指示を追加する

進行中のタスクを確認できたので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加に関連するセッションを選択します。正確なタイトルは Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールに表示されたアクセシビリティのセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが表示されるまで、セッションを数分間確認します。開始すると、以下のようなメッセージが表示されます。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![Copilot が作業中のエージェントタスクと、指示を追加するダイアログのスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを確認し、作業に反映することを確かめます。

## Copilot に作業を任せる

前回と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業中だった手順を完了すると、新しい依頼を作業の流れに取り込みます。

今回も数分かかります。その間に休憩して、ここまでに学んだことを振り返りましょう。

## まとめと次のステップ

この演習では、GitHub Copilot クラウドエージェントのタスクを監視して方向付ける中心的な場所である Copilot エージェントページについて学びました。このミッションコントロールを使うと、進行中と完了済みのタスクを追跡し、実行中の作業を確認できます。また、進行中のタスクに指示を追加して、範囲の調整や追加のガイダンスを行うこともできます。

この演習では、次のことを学びました。

- ミッションコントロールとエージェントページで、クラウドエージェントのタスクを監視しました。
- 進行中のセッションに指示を追加して、機能の追加を依頼しました。

Copilot がアクセシビリティ機能を実装している間に、Copilot が作成したプルリクエストを[反復的に改善する][next-lesson]方法を確認しましょう。
